# Blindspot AI

## Product and scope

Blindspot AI helps founders/student teams validate risky assumptions from real
interview evidence. Its personalized Library recommends real resources they can
use to build or test the idea. AI hypotheses and recommendations are not verified
market findings, security audits or license approvals.

The original Phase 01 delivered the backend. The founder website now lives in
`artifacts/blindspot-web` and consumes that same service; do not create a second
backend. Private API routes require verified Clerk sessions and project ownership.
Missing Clerk configuration must remain fail-closed in every environment;
never simulate authentication using caller IDs. Historical ownerless projects
remain quarantined; do not auto-claim or backfill them to a signed-in user.

Phase 02 is also explicitly backend-only: extend the core AI idea analysis
engine; do not rebuild Resource Intelligence, add feedback-analysis work or edit
the frontend. Preserve working endpoints and historical analyses.
**Why:** the user supplied a separate Phase 02 brief with these scope boundaries.
Its report is `repositories/blindspot-ai/docs/PHASE02_AI_ENGINE.md`.

Phase 03 is exclusively backend Resource Intelligence: extend the working
providers/search/storage; do not build frontend or reimplement Phase 02.
Preserve existing API fields and never fabricate external resources.
**Why:** the user's Phase 03 brief explicitly sets these boundaries.
Its report is `repositories/blindspot-ai/docs/PHASE03_RESOURCE_INTELLIGENCE.md`.
